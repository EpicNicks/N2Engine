- A project's physics.backend wins over the host's ApplicationOptions::physicsBackend; the host value (PHYSX, JOLT, AUTO newly added) is only the default for a project that does not say, because three of the four hosts (outside the allowed paths) still pass PHYSX and would otherwise make the setting dead.
- Jolt not in the build: a Deterministic project is refused through the existing physics-backend requirement (new NetworkEnvironment fields backendName, backendUnavailable, backendRequested); any other preset falls back to PhysX with a warning and the Physics row says so (Physics::ChooseBackend, pure and tested).
- The Deterministic preset's physics.backend row now has setting key physics.backend and value jolt (still L+S) but is table data only: Init does not write jolt into a project that did not ask, so a Deterministic project on the default physx is refused as before.
- The snapshot hash is named HashState (investigation 4.4) not StateHash (brief), and returns std::optional<uint64_t> so unsupported is not a hash value; BackendId() defaults to "unknown" (not pure virtual) and PhysX returns plain "physx" without a version suffix.
- PhysX SupportsSetState is now true: dynamic = setGlobalPose, velocities without autowake, then putToSleep or wakeUp; kinematic takes only a target pose; static only the pose; non-finite values and a zero rotation are refused; a near-unit rotation is passed untouched, others normalised. SupportsSnapshot stays false.
- Resync: named constant SimulationClock::MaxOwedSeconds = 1.0 checked at EndFrame; with a behind handler the report gets beyondLimit and the handler decides, with no handler the clock calls ResetAccumulator and logs one warning; applies to Authoritative and Deterministic, None unchanged. One existing test (LeavingANetworkModeThatIsBehind...) was changed from a 10 s debt to 40 ticks to stay under the bound.
- Mode reset is in Application::Shutdown only (not Init for none), tested through Shutdown without Init as the existing shutdown test does; Init for none still does not touch the mode.
- Network health row gets '; physics backend <BackendId()>' for non-none presets; the Authoritative set-state warning no longer appears for PhysX since it now supports set-state.

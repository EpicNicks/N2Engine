## Workflow

- PR body ends with: `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.
- "Merge when green": poll CI in the foreground (no background watchers) to completion, merge each PR when all checks pass, then continue. If master moved, merge master into the branch (never rebase) and re-run CI. Docs conflicts in `docs/assets/search-index.js`: `git checkout --theirs`, run `node docs/tools/build-search-index.mjs`, commit. Any docs change needs the search index regenerated and committed.
- Test on CI, not locally; local g++ syntax-only checks are fine (Vulkan SDK `C:\VulkanSDK\1.4.321.1`; gtest headers in main checkout `build/_deps/googletest-src`). Local build: `cmake --build build --target engine_tests --config Debug`; copy `build/bin/Debug/PhysX*.dll` from the main checkout into new worktrees.
- Working tree is CRLF (index LF); scripted edits must match `\r\n`.
- Linux Clang/GCC are stricter than MSVC: `template` keyword on dependent calls, concrete types in template fixtures, guard Lua tests with `N2ENGINE_SCRIPTING_ENABLED`, no range-for over a temporary's `.at()`. Vulkan tests fail on ANY validation warning, including perf warnings.
- CI flakes (macOS runner lost, iOS/metal-spike timeouts, apt.llvm.org): `gh run rerun <id> --failed` once; otherwise read logs (`gh api repos/EpicNicks/N2Engine/actions/jobs/<id>/logs --allow-escape-sequences`) and fix.
- Use worktrees under `.claude/worktrees`; remove each on merge (cd out first); keep E: free space above 10 GB.
- Don't touch `N2Engine-Electron-Frontend` without asking.
